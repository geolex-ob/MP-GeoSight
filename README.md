# MP-GeoSight 0.1.17
                                                                                                                                  
Мне очень не нравится родной GeoSight поэтому потихоньку создается этот проект как альтернатива.                                                                                                                                                                                              
                                                                                                                                  
                                                                                                                                  
Данные рисуются снизу вверх, актуально для тех кто работает на каждую вахту на разных типах станций (во избежание путаницы:) )                                                                                
                                                                                                                        
Программа для просмотра удаленного мониторинга ГТИ станций Разрез-2.                                                                       
                                                                                                                                      
                                                                                                                              
Проверялась в паре только с GeoScape 1.6.17.
                                                                                                                                                
Версия 0.0.5 - поправлена работа с датчиками, не совсем доделана функция сохранения настроек колонок.                                                    
                                                                                                                                                                                                     
Версия 0.0.6 - добавлена логарифмическая шкала.                                                                                                                                                                
                                                                                                                                    
Версия 0.1.3 - Метки перемещаются вместе с линиями при изменении масштаба. Добавлены коментарии. Исправлено общая продолжительность отображения графиков. Можно менять размер шрифтов в колонках. Исправлено скрытие цифровых меток.                                                                                                                                    
                                                                                                                                                      
Версия 0.1.9 - Исправлено поведение комментариев. Теперь можно настраивать ширину колонок. Добавлены 3 настраиваемых индикатора (можно вывести глубину шлама, газа и тому подобное). Внизу добавлены птички для графиков. Возвращена возможность удалить колонку. Исправлено меню настройки (неверный размер окна). В шкале с логарифмических масштабом точность до 0.0001 (с этого реализа в принципе можно пользоваться стало:))                                                                                                                                  
                                                                                                                      
Версия 0.1.11 - Добавлена полоска прокрутки графиков. Поправлена ширина колонки забоя и времени.
                                                                                                                              
Версия 0.1.17 - Добавлена глубина инструмента в колонку с глубиной забоя. Газы теперь в логарифмической шкале нормально падают в "0" если хроматограф выключен. Метку можно перемещать по шкале, вдруг не можите попасть куда хотите:) (в этой версии выложен ехе файл под windows 7, библиотеки от QT5 надо качать отдельно). Теперь чтобы удалить колонку надо это явно подтвердить.                                                                                                                          
                                                                                                                                                                      
Версия 0.1.19 - По просьбам трудящихся добавлена линейка для удобного просмотра всех данных в один момент времени, теперь метки с данными не наезжают друг на друга. Добавлена иконка.
